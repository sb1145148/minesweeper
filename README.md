# 扫雷 Minesweeper（纯静态）

原生 HTML + CSS + JavaScript 实现的扫雷游戏。**零依赖、零构建**，双击 `index.html` 即可运行，也可直接推送到 GitHub Pages 等任意静态托管平台。

本仓库同时存放**两个版本**，互不影响：

| 版本 | 文件 | 部署后地址 | 说明 |
| --- | --- | --- | --- |
| **原版（v1）** | `index.html` | `https://<你的用户名>.github.io/<仓库名>/` | 纯扫雷，不含任何彩蛋代码 |
| **彩蛋版（v2）** | `prank/index.html` | `https://<你的用户名>.github.io/<仓库名>/prank/` | 多一个"失败后自动跳转"彩蛋，见下 |

两个 `index.html` 各自是**完全独立、自包含的单文件**（HTML / CSS / JS 全内联），没有任何共享依赖，改其中一个不会影响另一个。

## 文件

| 文件 | 说明 |

| `index.html` | 原版，纯扫雷（结构 / 样式 / 逻辑内联在单文件中） |

## 运行方式

1. **本地直接运行**：双击 `index.html`（原版）或 `prank/index.html`（彩蛋版），用任意现代浏览器打开即可，`file://` 协议下功能完整。
2. **本地起静态服务（可选）**：
   ```bash
   cd 本目录
   python3 -m http.server 8000
   # 原版：  http://localhost:8000/
   # 彩蛋版：http://localhost:8000/prank/
   ```
   仅用 `python3`/`npx serve` 这类静态文件服务即可，项目本身不需要任何后端。

## 玩法

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 翻开格子 |
| 右键单击 | 插旗 / 取消旗子 |
| 双击已翻开的数字格 | 若周围旗数等于该数字，快速展开周围 8 格 |
| 触屏点按 | 翻开格子 |
| 触屏长按（约 0.42 秒） | 插旗 / 取消旗子 |
| 触屏双击数字格 | 快速展开周围 8 格 |
| 「标记模式」按钮 | 打开后，点按即插旗（适合触屏误触场景） |

- 难度：初级 9×9/10 雷、中级 16×16/40 雷、高级 16×30/99 雷；**切换难度会立即开新局**。
- **首击安全**：第一次点击的格子及其周围 8 格内保证不生成地雷（地雷在首击后才布置），首击必为 0 区域并自动展开。
- 翻开所有非雷格即胜利；踩到雷即失败并展示全部地雷（错误插旗会高亮）。
- 计时器在首次点击时启动，胜利 / 失败时停止。

## 彩蛋：失败后自动跳转（仅 `prank/index.html`）

踩到雷后，棋盘先展示完整的爆炸现场，停留 5 秒，随后**随机跳转到 7 条 b23.tv 链接中的一条**。配置项集中在 `prank/index.html` 顶部的 `REDIRECT` 对象里：

```js
var REDIRECT = {
  enabled: true,        // 总开关，false = 关掉跳转
  urls: [ /* 7 条 b23.tv 链接 */ ],
  delayMs: 5000,        // 踩雷后停留多久再跳（毫秒）
  target: 'self',       // 'self' = 当前页跳走；'blank' = 新标签页打开（原页保留）
  shuffleBag: true,     // true = 抽签袋：随机轮流，一轮内不重复
  cancellable: true     // true = 倒计时期间显示「停止跳转」按钮
};
```

随机策略是**抽签袋（shuffle bag）**而不是纯随机：每轮把 7 条链接洗牌后依次取用，取完再洗下一轮。这样既随机，又保证**不会连着两次跳到同一个链接**（轮内不重复；跨轮洗牌时也会避开与上一次相同的链接）。

运行时可以用 URL 参数覆盖，方便分享或自测：

| 参数 | 作用 |
| --- | --- |
| `?redirect=off` | 关闭跳转（分享"安全版"或做自动化测试时用） |
| `?redirect=on` | 强制开启 |
| `?delay=3000` | 改停留时长 |
| `?target=blank` | 用新标签页打开，保留游戏页面 |
| `?cancel=off` | 不给「停止跳转」按钮 |

跳转行为细节：

- 只在**失败**时触发，胜利不跳。
- 倒计时期间状态栏会显示剩余秒数并呼吸闪烁，旁边出现「停止跳转」按钮（`cancellable: true` 时）。
- 点「重新开始」或切换难度会**取消**尚未执行的跳转。
- `target: 'blank'` 时会在点击的同一个手势里预开一个空白标签页，倒计时结束后再让它导航过去——否则会被浏览器当作弹窗拦截。
- 跳转是当前标签页导航（`location.href`），不依赖弹窗权限，因此弹窗拦截器不会挡住它。

> 想分享"干净"的彩蛋版链接给别人：在 `/prank/` 后面加 `?redirect=off` 即可。

## 主题

配色以 DeepSeek Harness 的主题变量 `--dsw-alias-*`（配合 `--dsw-static-*`）为首选色源，两个文件都**不覆盖任何 `--dsw-*` 变量**，所有引用都写成
`var(--dsw-alias-xxx, <内置兜底值>)`：

- **嵌入 DSH 运行时**：自动继承宿主明暗主题，并隐藏「深色/浅色」切换按钮（由宿主控制）。
- **独立打开**：使用内置的明暗兜底配色，跟随系统 `prefers-color-scheme`，也可用右上角按钮手动切换（记忆在 `localStorage`）。

## 部署到 GitHub Pages

仓库的目录结构就是部署结构，**不需要任何构建步骤**：

```
<仓库根>/
├── index.html          →  /            （原版）
├── prank/index.html    →  /prank/      （彩蛋版）
├── README.md
└── CHANGELOG.md
```

```bash
git init -b main
git add index.html prank/index.html README.md CHANGELOG.md
git commit -m "feat: 纯静态扫雷 + 失败跳转彩蛋版"
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

然后在 GitHub 仓库页面：**Settings → Pages → Build and deployment**
- Source 选 `Deploy from a branch`
- Branch 选 `main`，目录选 `/ (root)`，Save

等 1 分钟左右：

- 原版：`https://<你的用户名>.github.io/<仓库名>/`
- 彩蛋版：`https://<你的用户名>.github.io/<仓库名>/prank/`

（两个入口的文件名都必须是 `index.html`，本仓库已满足，无需额外配置。）

其他静态托管平台（Cloudflare Pages、Vercel、Netlify、Gitee Pages 等）同样是"选择仓库 → 无需构建命令 → 输出目录填 `/`"即可。
